# Automation Research

## Bash Script
A Bash script is a text file that contains a list of terminal commands that run one after another. The first line, `#!/bin/bash` (the shebang), tells Linux to use the Bash program to run the file.

## Variables
A variable stores a value once so it can be used many times in a script. Using `$BACKUP_DIR` instead of typing the folder path each time saves effort, and if the path changes I only need to edit one line.

## Cron Job
A cron job is a task that Linux runs automatically at a set time or schedule. It is essential for cloud operations because backups and maintenance happen on time without a person having to remember them.
